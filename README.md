# えでんごん / Eden Gon'（LINEグループ用 絵伝言ゲーム）

「絵で伝言」＋「gonna（伝えるつもり）」。

LINE公式アカウント（Bot）をグループLINEに招待して遊ぶ、テレストレーション風のゲームです。
GitHub → Netlify にデプロイするだけで動きます。サーバー代・DB契約は不要です。

---

## 遊び方（グループ内で送る言葉）

| 言葉 | 動き |
|---|---|
| 参加 / 抜ける | 参加受付 |
| 開始 | ランダムに順番を決めてスタート |
| スキップ | 今の番の人を飛ばす（寝落ち対策） |
| 状況 | 今だれの番か再表示 |
| モード | 「描く→答える交互」（標準）⇔「絵だけ伝言」を切替 |
| 難易度 | お題の難しさを ミックス→かんたん→ふつう→むずかしい の順に切替 |
| つづき | 結果発表の続きを表示 |
| リセット | 最初からやり直し |
| ヘルプ | 言葉の一覧 |

- 描くのは60秒、答えるのは30秒
- 自分の番の人だけがボタンを開けます（他の人は「あなたの番ではありません」）
- 最初の人だけ、お題を1回だけ交換できます（交換すると描いた絵は消え、60秒を測り直し）
- お題は同じグループで最近出たものを避けて選ばれます
- 最後の人が終わると「🎉 結果発表！」とお題が出て、あとは「つづき」を押すたびに 絵 → 回答 → 絵 … と1つずつめくれます

## セットアップ（はじめての人向け）

全体の流れ：
**① 公式アカウント（Bot）を作る → ② LINEログインチャネルを作る → ③ Netlifyに公開 → ④ LIFFを作る → ⑤ つなぐ → ⑥ 公開して遊ぶ**

### ① LINE公式アカウント（Bot本体）を作る
1. 「LINE Official Account Manager」（https://manager.line.biz/）に自分のLINEアカウントでログイン
2. 「アカウントを作成」→ 名前は **えでんごん**などを入力して作成。業種は「個人」系でOK
3. 作ったアカウントを開き、右上の **設定** を開く
   - **アカウント設定** →「グループ・複数人チャットへの参加」を **許可する**
   - **応答設定** →「応答メッセージ」を **オフ**、「Webhook」を **オン**
   - **Messaging API** →「Messaging APIを利用する」を押す
     - プロバイダーを聞かれたら新規作成（例：低めの猫）。**このプロバイダー名を覚えておく**
4. 「LINE Developers」（https://developers.line.biz/console/）にログインすると、さっきのプロバイダーの中にチャネルができています。開いて次の2つを控える
   - 「チャネル基本設定」タブ →**チャネルシークレット**
   - 「Messaging API設定」タブ → 一番下の **チャネルアクセストークン（長期）** の「発行」を押してコピー
   - ついでに同じタブの **QRコード** を保存（友だち追加・グループ招待に使う）

### ② LINEログインチャネルを作る（お絵かき画面用）
1. LINE Developers で **①と同じプロバイダー** を開く（違うプロバイダーだと本人判定ができません）
2. 「新規チャネル作成」→「LINEログイン」
   - アプリタイプ：**ウェブアプリ** にチェック
   - チャネル名などを入力して作成
3. 「チャネル基本設定」タブの **チャネルID** を控える

### ③ Netlifyに公開
1. このフォルダをGitHubの新しいリポジトリにpush
2. Netlifyで「Add new site → Import an existing project」→ そのリポジトリを選んでデプロイ
3. 発行されたURL（例：`https://xxxx.netlify.app`）を控える
4. Site configuration → **Environment variables** に4つ登録
   | 名前 | 中身 |
   |---|---|
   | `LINE_CHANNEL_SECRET` | ①のチャネルシークレット |
   | `LINE_CHANNEL_ACCESS_TOKEN` | ①のチャネルアクセストークン（長期） |
   | `LINE_LOGIN_CHANNEL_ID` | ②のチャネルID |
   | `LIFF_ID` | ④で取得（今は仮に `x` でOK） |

### ④ LIFFアプリを作る（LINEログインチャネルの中）
1. ②のLINEログインチャネル →「LIFF」タブ →「追加」
   - LIFFアプリ名：えでんごん
   - サイズ：**Full**
   - エンドポイントURL：`https://xxxx.netlify.app/liff/`（最後の `/` まで）
   - Scope：**openid**、**profile**、**chat_message.write** にチェック（chat_message.writeは「すべて表示」を押すと出ます）
   - 友だち追加オプション：On（Normal）でOK
2. 発行された **LIFF ID**（`1234567890-AbCdEfGh` のような形）を、Netlifyの `LIFF_ID` に入れ直す
3. Netlifyで **Deploys → Trigger deploy** で再デプロイ（環境変数は再デプロイで反映されます）

### ⑤ Webhookをつなぐ（Messaging APIチャネルの中）
1. ①のチャネル →「Messaging API設定」タブ
2. Webhook URL に `https://xxxx.netlify.app/webhook` を入れて「更新」
3. 「検証」を押して **成功** と出ればOK
4. 「Webhookの利用」をオン

### ⑥ 公開して遊ぶ
1. ②のLINEログインチャネルの上部にある「開発中」を **「公開済み」** に切り替え
   （開発中のままだと、自分以外がお絵かき画面を開けません）
2. ①のQRコードから公式アカウントを友だち追加 → グループLINEに招待
3. グループで「参加」→ みんな参加したら「開始」

## うまく動かないとき
- **「検証」が失敗する**：Netlifyの環境変数が入っているか、入れた後に再デプロイしたか確認
- **グループに招待できない**：①-3の「グループ・複数人チャットへの参加」が許可になっているか
- **Botが何も返さない**：「応答メッセージ」がオフ、「Webhookの利用」がオンか確認。Netlifyの Logs → Functions → webhook にエラーが出ていればそれを見る
- **ボタンを押すとエラー**：LIFFのエンドポイントURL、`LIFF_ID`、⑥-1の「公開済み」を確認
- **自分の番なのに「あなたの番ではありません」**：①と②のプロバイダーが同じか確認

## 調整しやすい場所（lib/game.mjs）
- `TIME_LIMIT`：制限時間（描く60秒・答える30秒）
- `PROMPTS`：お題リスト（かんたん／ふつう／むずかしい の3つ。行を足せば増えます）
- `MIN_PLAYERS`：最少人数

## 既知の制限（プロトタイプ）
- 同じ瞬間に複数人が「参加」すると、まれに1人分が反映されないことがあります（もう一度送ればOK）
- 番の人がボタンを押さずに放置した場合は、誰かが「スキップ」で進めてください
- LINEの外（普通のブラウザ）で開いた場合は、トークへの自動送信の代わりにプッシュで次の人を案内します（こちらは無料通数を消費します）
